# Stocker Studio

React + Vite UI for Agent sessions, chat, execution inspection, and checkpoints.

- [Architecture and source map](../docs/studio/architecture.md)
- [Requirements, dependencies, and scripts](package.json)
- [Backend service](../agent/README.md)

Run `make studio` from the repository root or `pnpm run dev` here for hot reload.
Browser test configuration is in [playwright.config.ts](playwright.config.ts).
Retained upstream components are attributed in [UPSTREAM.md](UPSTREAM.md) and
[LICENSE](LICENSE). The standalone [Chat bubble](../chat/README.md) is planned.
